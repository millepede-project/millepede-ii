# Millepede-II

![MP2 logo](./mp2-logo.png)

Millepede II is a package for linear least squares fits with a large number of parameters. Developed for the alignment and calibration of tracking detectors.


Please check out 
- the [Package Documentation](http://millepede.pages.desy.de/millepede-ii) 
- the [Wiki](https://gitlab.desy.de/millepede/millepede-ii/-/wikis/home)

for instructions on how to set up and use Millepede-II.
